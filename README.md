# Employee Management System SQL Project

This project demonstrates basic SQL concepts using MySQL.

## Concepts Covered

- DDL Commands
  - CREATE
  - ALTER
  - DROP
  - TRUNCATE

- DML Commands
  - INSERT
  - UPDATE
  - DELETE

- DQL Commands
  - SELECT
  - WHERE
  - ORDER BY
  - DISTINCT
  - LIMIT

- Constraints
  - PRIMARY KEY
  - FOREIGN KEY
  - UNIQUE
  - NOT NULL

- TCL Commands
  - COMMIT
  - ROLLBACK
  - SAVEPOINT

## Database Tables

1. Department
2. Employee
